## 为什么你的号0播放：风控到底在看什么

TikTok的风控不是"查一下IP在哪个国家"这么粗。它同时看四个维度：

**IP属性**。这个IP是真实家庭住户的宽带，还是云服务商的机房服务器。机房IP在Scamalytics、ipinfo这类数据库里被直接标记为"数据中心/代理"，平台扫到就降权。

**IP关联度**。同一个IP下挂了多少个账号。挂了五十个号，平台会把它们归为"同一来源"，甚至判定为群控或工作室行为。

**DNS解析位置**。这一条最容易被忽略。IP伪装成美国，但DNS还走国内运营商，等于"脸是美国的，口音是中国的"，一样被识破。

**黑名单历史**。这个IP段以前有没有被拿去做过黑灰产。机房IP被无数人共用，历史污点多，平台天然不信任。

据圈内人士反映，几年前曾有人向TikTok提供大量VPS IP段数据，平台随后明显加大了对机房IP的封锁力度，一批原本能正常跑量的账号突然集体陷入0播放。这个说法没有得到官方确认，但它解释了为什么同样发视频，有人有播放有人没有——差别不在内容，在IP的出身。

## IDC、ISP、原生、双ISP：四个词搞清再买

这四个词经常被混着用，实际指向完全不同的东西。

**IDC IP（机房IP）**：云服务商提供的IP，特征明显、成本极低。适合纯浏览、或者"不怕阵亡"的矩阵号测试。用它发视频，大概率0播放。

**ISP IP（静态住宅IP）**：海外当地运营商分配给家庭用户的宽带，服务商租用后固化成静态IP。在TikTok眼里和真实居民没区别。市场价通常在5-15美元/月。

**原生IP**：真正的含义是IP的注册地和服务器物理位置一致。非原生IP虽然IP库显示美国，服务器可能架在欧洲，通过技术"广播"到美国，结果就是"跳区"——你想做美区内容，视频被推给了英国用户。

**双ISP**：IP同时归属两家当地运营商，平台判定为"住宅用户"的可信度最高，欺诈值通常为0。

选择优先级很明确：

**双ISP住宅原生IP > 单ISP住宅IP > 普通原生IP > 数据中心IP**

买之前用ipip.net或whoer.net测一遍。关键看两点：属性显示为"住宅用户"，DNS解析地址和IP地址在同一个国家、最好同一个州。whoer.net的DNS那一项必须是绿的。

## 配置网络环境的五条硬规则

### 一、一个IP只绑一个账号

这是最没有商量余地的一条。同一个IP挂多个号，最直接的后果是一个账号违规、所有账号一起死。风险大致是这样分布的：

| 同IP账号数 | 风险等级 | 实际情况 |
| --- | --- | --- |
| 1个 | 安全 | 标准配置，平台视为独立真实用户 |
| 2-3个 | 中高风险 | 短期可能不被发现，关联隐患长期存在 |
| 4个以上 | 极高风险 | 接近群控行为，封号只是时间问题 |

IP要真（住宅）、要稳（静态）、要独立（一账号一IP），三件事缺一不可。

### 二、要静态，不要动态

动态IP每次连接地址都变，登录轨迹频繁跳跃，平台第一反应就是异常验证。静态住宅IP长期固定在一个位置，符合真实用户的上网习惯。

### 三、地区必须匹配目标市场

TikTok是区域化分发。做美区就用美国IP，做越南就用越南IP。用新加坡IP做美区内容，流量分发从一开始就是错的。

### 四、DNS不能泄露

IP换成美国的，DNS也要跟着走。检测工具里DNS项目和IP在同一国家，才算合格。

### 五、不要用机场共享节点，不要频繁换城市

机场节点是几千人共用的池子。TikTok的连坐机制意味着同IP下任何一个人违规，所有人都被牵连；而且机场IP多为数据中心IP，行为模式复杂，很容易被判可疑。今天连洛杉矶、明天连纽约这种"瞬间移动"，同样会被算法立刻标记。

如果要做多账号，光有独立IP还不够，设备指纹和浏览器环境也会被用来做关联判断，每个账号需要一套独立的浏览器环境。多店铺场景同理：每个店铺绑定一套固定的运行环境和固定出口地址，运营期内不要变动。判断隔离是真是假有个简单办法——把A店账号在B店环境里登录，如果平台一点异常提示都没有，说明这个"隔离"是假的。

最好只绑一个。这不是技术上限问题，是风险控制问题。2-3个属于中高风险，4个以上基本等于群控，封号只是时间问题。

**IDC和ISP到底差在哪？**

IDC是机房IP，ASN一看就是云服务商，平台默认不信任；ISP是住宅IP，来自真实家庭宽带运营商，平台视为普通居民。这个差别直接决定视频能不能被推出去。

**原生IP怎么检测？**

用ipip.net或whoer.net查。看两个指标：属性是否显示"住宅用户"，DNS解析地址是否和IP在同一国家甚至同一州。两个都对，才算合格。

**DNS泄露怎么查？**

还是whoer.net，DNS那一项必须是绿色。红色或者显示国内运营商，就是泄露了。

**直播需要多大带宽？**

按分辨率算：720p 10-20Mbps，1080p 20Mbps以上。按推流方式算：手机直播5Mbps起，OBS推流6Mbps起。多账号矩阵按账号数量叠加。但真正决定有没有流量的是IP属性，带宽只决定推流稳不稳。

**退款怎么算？**

VPS类48小时内不满意无条件退。VDS类（静态住宅IP系列）只退网站余额。另外，48小时内带宽超分配5%或20GB、或存在滥用行为的，不在退款范围内。
